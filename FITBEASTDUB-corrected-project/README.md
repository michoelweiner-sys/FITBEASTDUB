# FITBEASTDUB Android project

This project is an offline-first Android WebView app. Workout programs and workout history are saved on the device using browser local storage.

## Build an APK on GitHub

1. Upload the contents of this folder to the root of the GitHub repository (not the containing folder).
2. Open the repository's **Actions** tab.
3. Select **Build FITBEASTDUB APK** and click **Run workflow** (or wait for the automatic build after a push).
4. Open the completed run and download the **FITBEASTDUB-APK** artifact. Extract it to get `app-debug.apk`.

The APK is a debug build for testing and direct installation. It is not a Play Store release-signed APK.
